# Hotel Pet API

API REST para gestão de um hotel para pets: quartos, tutores, pets, reservas e pagamentos.

Projeto em desenvolvimento. Feito com Python, FastAPI e SQLAlchemy.

## Como rodar

    python -m venv venv
    .\venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    uvicorn app.main:app --reload

Documentação em http://127.0.0.1:8000/docs
